
# PromptVault 🚀

A high-end personal prompt knowledge base.

## 如何部署到你的 GitHub Pages

1. **新建仓库**：在 GitHub 上创建一个新的仓库。
2. **上传代码**：将本项目的所有文件上传到该仓库。
3. **设置 API Key**：
   - 进入仓库的 **Settings** > **Secrets and variables** > **Actions**。
   - 点击 **New repository secret**。
   - 名称填写 `API_KEY`，内容填写你的 Google Gemini API Key。
4. **开启 Pages**：
   - 进入 **Settings** > **Pages**。
   - 在 **Build and deployment** 下，确保 Source 设置为 `GitHub Actions`。
5. **完成**：每次你推送代码到 `main` 分支，GitHub 都会自动为你部署更新。

## 功能特点
- **Qatchup 风格设计**：极简、现代、动感。
- **AI 智能演化**：利用 Gemini API 自动优化你的 Prompt。
- **版本管理**：记录每一次 Prompt 的进化历程。
- **响应式布局**：完美适配桌面与移动端。
